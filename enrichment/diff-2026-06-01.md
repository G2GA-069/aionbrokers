**Selection logic:** ISO week 23 → slot `(23−1) % 8 = 6` → 50 firms at `idx % 8 == 6`, name-sorted, first 19 taken; plus 6 low-confidence firms (0 people, no contact email, notes < 100 chars, has website), for 25 total (excluding 5 AXIAL-series entries with no website).

**week_of_year used:** 23 (ISO week for 2026-06-01, verified via Python `datetime.isocalendar()`)

**WebFetch calls made:** ~35 attempted; **all returned HTTP 403 Forbidden** from this remote execution environment. This appears to be a systemic issue — the container IP is blocked by most UK corporate website WAFs and CDNs (Cloudflare, etc.). Phase 1 health checks and all Phase 2 team-page enrichments were performed via WebSearch instead. One ECONNREFUSED result (CGA Day Nurseries) is a genuine signal distinct from the 403 pattern.

**What didn't work:**
- Direct team-page fetches via WebFetch returned 403 across all 15 Phase 2 firms attempted; paths tried included `/team`, `/our-team`, `/people`, `/about`, `/about-us`
- Companies House search page also returned 403 on direct fetch
- Insider Media article for Pura Advisory returned 403 on direct fetch; content obtained via aggregator/search snippets instead

**Previous open enrichment PRs:** None found (checked `g2ga-069/aionbrokers` — 0 open PRs as of run time)

**Data quality caveat:** Because team data was sourced indirectly (press releases, Mergr, ZoomInfo snippets), email addresses for Phase 2 new contacts could not be confirmed. All Phase 2 new-person entries are marked `confidence: medium`. G2G should verify emails before outreach.
